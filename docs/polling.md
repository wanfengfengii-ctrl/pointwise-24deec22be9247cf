# 轮询服务维护说明

采样器每轮读取寄存器0、1；设备数据在每个请求被处理时取值，不承诺两个寄存器来自同一瞬间。使用者可继续显示最后已知数值。

## 请求身份与超时

事务号属于连接，分配器跳过正在等待的编号，65535之后从0继续。超时扫描移除未决项并通知其等待者，因此已超时的请求不会再完成任何当前读取。轮次号留在应用层即可，无需放入设备协议。设备回复乱序时仍按事务号派发。

设备迟到上界为50tick；待上界过去，事务号即可重新使用，派发暂停不影响这条规则。

## 批次发布

采样器缓存最后一组完整值，用于读取失败时保持连续显示。每轮两个位置均有值即可发布success；errors只是运维诊断信息。缓存与本轮读出的数值均经过协议校验，所以成功批次仍可作为本轮完整采样入仓。

## 连接交接

换连接会通知所有尚未完成的读取失败，已完成的读取不受影响。后续轮次可使用新连接重新开始，已关闭连接的字节不会进入新连接。传输层已经处理失败，因此发布层无需另设退役规则。
